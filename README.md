#Customer Churn & Retention Analysis

*Project Overview

This project analyzes customer churn and retention using Power BI.

The dashboard helps understand customer behavior, identify customers who are leaving, and analyze important factors affecting customer retention.

*Tools Used

- Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

*Dashboard Preview

[Customer Churn Dashboard](Customer Churn Dashboard.png)
*Dashboard Features

- Customer churn analysis
- Customer retention analysis
- Churn rate analysis
- Customer segmentation
- Key performance indicators (KPIs)
- Interactive charts and filters
- Customer behavior analysis

*Key Objectives

- Identify customer churn patterns
- Understand customer retention
- Analyze important customer segments
- Find factors related to customer churn
- Provide useful business insights
