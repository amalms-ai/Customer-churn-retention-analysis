#Customer Churn & Retention Analysis

Interactive Customer Churn & Retention Analysis Dashboard built using Microsoft Power BI.

#Project Overview

This project analyzes customer data using Microsoft Power BI to understand customer churn, retention, customer behavior, and the factors that influence customers leaving a service.

The dashboard helps identify churn patterns and provides insights that can support customer retention and business decision-making.
